Qual tubo a vácuo usar para cada exame?

A cor da tampa do tubo a vácuo diz qual aditivo ele tem — e o aditivo é o que prepara o sangue para cada tipo de exame. Usar o tubo errado é a causa nº1 de recoleta. Este guia resume qual tubo usar para cada exame e a ordem de coleta recomendada.

Ordem de coleta (para não contaminar)

Quando se coleta mais de um tubo na mesma punção, a ordem evita que o aditivo de um tubo contamine o próximo. A sequência recomendada é: 1) hemocultura → 2) azul (citrato) → 3) vermelha/amarela (soro) → 4) verde (heparina) → 5) roxa (EDTA) → 6) cinza (fluoreto).

Perguntas frequentes

Qual tubo usar para exame de glicose?

O tubo de tampa cinza, com fluoreto de sódio, que impede a glicólise e mantém a glicemia estável até a análise.

Posso usar o tubo de soro (amarelo) para hemograma?

Não. Hemograma precisa do tubo roxo com EDTA, que preserva as células. O tubo amarelo coagula a amostra.

Por que o tubo azul de coagulação precisa ser enchido até a marca?

Porque o exame depende da proporção exata entre sangue e citrato. Tubo pouco cheio altera o resultado.
